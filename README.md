# Online Chess — Android / Kotlin

Онлайн-шахматы для двух игроков на разных телефонах. Первый игрок создаёт комнату и получает шестизначный код, второй вводит этот код. Позиция и ходы синхронизируются через Cloud Firestore. Завершённые партии появляются в истории матчей.

## Что уже работает

- создание комнаты и подключение второго игрока;
- анонимная авторизация двух телефонов;
- шахматная доска и только легальные ходы;
- шах, мат, пат, рокировка, взятие на проходе и ничья;
- синхронизация позиции в реальном времени;
- сохранение победителя и список последних 50 матчей.

## Один раз подключить Firebase

1. Откройте [Firebase Console](https://console.firebase.google.com/) и создайте проект.
2. Добавьте Android-приложение с package name `com.nataliia.onlinechess`.
3. Скачайте `google-services.json` и положите его в папку `app/`.
4. В `app/build.gradle.kts` раскомментируйте `id("com.google.gms.google-services")`.
5. В Firebase включите **Authentication → Anonymous**.
6. Создайте **Cloud Firestore** и опубликуйте правила из `firestore.rules`.
7. Откройте папку проекта в Android Studio, дождитесь Gradle Sync и запустите на двух телефонах.

## Проверка

На телефоне №1 введите имя и нажмите «Создать новую игру». На телефоне №2 введите другое имя, код с первого телефона и нажмите «Подключиться». Белые ходят первыми.
